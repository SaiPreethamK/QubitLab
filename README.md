# QubitLab

### AI-Based Interactive Quantum Algorithm Learning Platform

QubitLab is an interactive learning platform designed to help students and faculty understand quantum computing concepts through visualization, experimentation, AI-assisted learning, and assessment.

<img width="1847" height="875" alt="image" src="https://github.com/user-attachments/assets/03f068af-26d6-47a6-9e7d-b28c2e234ff8" />


## 🚀 Features

- Interactive quantum concept learning
- Quantum circuit builder
- Quantum gates: X, Y, H, S, Z, CNOT
- Bloch Sphere visualization
- AI Tutor powered by Google Gemini
- Topic-wise learning resources
- Interactive quizzes and assessment
- Visual and hands-on quantum experimentation

## 🎯 SIH Problem Statement

**SIH26140 — AI-Based Interactive Quantum Algorithm Learning Platform**

Quantum computing concepts can be difficult for beginners because many ideas such as qubits, superposition, quantum gates, and entanglement are highly abstract.

QubitLab aims to make these concepts easier to understand by combining explanations, interactive circuit building, visualization, AI-assisted learning, and assessment in one platform.

## 💡 Our Solution

QubitLab provides an interactive environment where learners can:

**Learn → Build → Simulate → Visualize → Assess**

The platform combines conceptual learning with hands-on experimentation to make quantum computing more accessible and engaging.

## 🤖 AI Integration

The AI Tutor uses the **Google Gemini API** to provide AI-assisted responses and help users explore quantum-computing concepts.

### API Endpoints

- `/api/tutor` — Connects the QubitLab frontend to Gemini
- `/api/health` — Checks server status
